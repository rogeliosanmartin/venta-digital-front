# ANA — 2026-08-30 — Frontend Venta Digital

## Objetivo del día

Preparar el frontend para desplegarse en Coolify y llevar el estado de
`develop` a `main`.

## Contenedorización

- Build multi-stage con Node 22 y `npm ci`.
- La variable `VITE_API_URL` se recibe como argumento de build.
- Nginx sirve los archivos estáticos por el puerto 80.
- Se agregó fallback a `index.html` para las rutas de Vue Router.
- Los assets versionados usan caché de larga duración y `index.html` no se
  almacena en caché.
- La imagen incluye un healthcheck HTTP.
- `.dockerignore` excluye dependencias, builds, archivos locales y variables
  de entorno.

## Coolify

- Tipo de build: Dockerfile.
- Puerto expuesto: 80.
- Configurar `API_UPSTREAM` como variable de runtime con la URL interna del
  backend.
- Nginx recibe `/api` en el mismo origen del frontend y lo reenvía al backend,
  evitando dependencias de CORS y contenido mixto.

## Correcciones para build productivo

- Se completó `withoutInterest` en los datos de prueba de la venta.
- Los helpers monetarios ahora aceptan valores desconocidos provenientes del
  API y los normalizan internamente.
- Se corrigió el uso tipado de `GState` en la marca de agua del PDF.
- Se eliminaron variables de respuesta HTTP que no se utilizaban.
- Se actualizó la dependencia transitiva vulnerable `nanoid`.

## Validación

- `npm run build` finaliza correctamente.
- La imagen Docker se construye sin vulnerabilidades reportadas por `npm`.
- Nginx pasa su validación de configuración y entrega correctamente rutas
  internas de la SPA.
